# Fonts

**Noto Color Emoji** (Google), for emoji made after 2017. Download
`NotoColorEmoji.ttf` (the PNG version) from Google's noto-emoji project:
https://github.com/googlefonts/noto-emoji, folder `fonts`. Put it in this
folder or in the project folder; the build copies it next to the programs.
It is licensed under the SIL Open Font License 1.1: see `OFL.txt` here,
which goes with it.

Without it, Nexus uses Fyne's own emoji, which lack the newer ones.
