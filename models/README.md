# Models

**RNNoise** (Xiph.org, BSD licence), for Strong noise suppression.
Download `rnnoise_data-0b50c45.tar.gz` from
https://media.xiph.org/rnnoise/models/ and unpack its `src` files into the
`rnnoise-v0.2/rnnoise-v0.2/src` folder; the build then makes `rnnoise.bin`
here with `tools/rnnoise-weights` and copies it next to the programs.

Without it, Noise Suppression offers Off and Standard only.
